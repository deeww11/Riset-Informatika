# Research Mind Map

Folder ini berisi peta konsep (*research mind map*) yang menggambarkan hubungan antara permasalahan penelitian, tujuan, metode, proses analisis, dan luaran yang diharapkan.

## Topik Penelitian

**Perbandingan Algoritma Apriori dan FIN untuk Analisis Pola Pembelian dan Rekomendasi Paket Bundling Produk pada Data Transaksi Swalayan**

## Komponen Mind Map

- Permasalahan dan latar belakang penelitian.
- Dataset transaksi swalayan.
- Tahapan preprocessing data.
- Penerapan algoritma Apriori dan FIN.
- Perbandingan hasil *frequent itemset*.
- Analisis pola pembelian.
- Rekomendasi kandidat paket bundling.
