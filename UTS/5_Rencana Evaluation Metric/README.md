# Rencana Evaluation Metric

Folder ini berisi dokumen perencanaan evaluasi untuk membandingkan algoritma Apriori dan FIN pada proses pencarian *frequent itemset*.

## Aspek Evaluasi

1. **Jumlah frequent itemset** — membandingkan jumlah pola yang ditemukan pada setiap nilai minimum support.
2. **Kesesuaian hasil** — memeriksa kesamaan kombinasi produk dan nilai support count dari kedua algoritma.
3. **Waktu eksekusi** — membandingkan waktu proses algoritma dengan prosedur pengukuran yang konsisten.
4. **Analisis aturan asosiasi** — menggunakan support, confidence, dan lift untuk menganalisis pola pembelian yang ditemukan.

## Parameter Pengujian

Pengujian direncanakan menggunakan minimum support sebesar 0,05%, 0,10%, dan 0,20%. Minimum confidence sebesar 10% digunakan dalam analisis aturan asosiasi.
