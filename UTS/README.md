# Ujian Tengah Semester (UTS)

Folder ini berisi dokumen perencanaan dan persiapan penelitian untuk memenuhi tugas UTS mata kuliah Riset Informatika.

## Daftar Dokumen

1. **Proposal Penelitian** — dokumen rancangan penelitian.
2. **Dataset Rencana Riset Kecil** — dokumentasi dataset yang direncanakan untuk penelitian.
3. **Research Gap** — identifikasi kesenjangan penelitian berdasarkan penelitian terdahulu.
4. **Research Mind Map** — pemetaan konsep dan alur pemikiran penelitian.
5. **Rencana Evaluation Metric** — rencana metrik yang digunakan untuk mengevaluasi dan membandingkan algoritma.

Setiap dokumen disimpan pada folder masing-masing agar mudah diperiksa dan diperbarui selama proses penelitian.
