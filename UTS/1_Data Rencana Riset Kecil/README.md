# Dataset Rencana Riset Kecil

Folder ini berisi dokumentasi dataset yang direncanakan untuk penelitian perbandingan algoritma Apriori dan FIN.

## Sumber Dataset

Dataset utama berasal dari data transaksi penjualan swalayan selama periode Januari–Desember 2025.

## Gambaran Dataset

- Jumlah transaksi: 35.218 transaksi.
- Jumlah kode produk unik: 5.517.
- Sumber data awal: berkas DBF.
- Data olahan: data detail produk per transaksi dan data keranjang belanja (*transaction basket*).

## Pemanfaatan Dataset

Dataset digunakan untuk membentuk keranjang transaksi dan menemukan kombinasi produk yang sering dibeli secara bersamaan menggunakan algoritma Apriori dan FIN.

## Catatan

Folder ini berisi dokumentasi dan informasi dataset rencana penelitian. Berkas transaksi asli tidak boleh dipublikasikan apabila mengandung informasi internal atau bersifat rahasia.
