# Proposal Penelitian

Folder ini berisi dokumen proposal penelitian untuk mata kuliah Riset Informatika.

## Judul Penelitian

**Perbandingan Algoritma Apriori dan FIN untuk Analisis Pola Pembelian dan Rekomendasi Paket Bundling Produk pada Data Transaksi Swalayan**

## Isi Dokumen

Proposal penelitian mencakup latar belakang, rumusan masalah, batasan masalah, tujuan dan manfaat penelitian, landasan teori, penelitian terdahulu, serta metodologi penelitian.
